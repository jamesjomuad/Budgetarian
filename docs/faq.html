Frequently asked questions

Everything you need to know about Budgetarian. Can't find what you're looking for? Open an issue on GitHub.

Budgetarian is a mobile-first, offline personal budgeting app. It helps you organize your money into budgets (period-based containers like "November 2026"), track income and expenses, and understand your spending patterns. Everything runs locally on your device — no account, no cloud, no data collection.

A budget is a period container with a name, start date, and end date. It's not an envelope with a spending limit — "spent" and "remaining" are always derived from the transactions you record inside it. You can create budgets for months, quarters, projects, or any time period.

A folder groups related budgets together. You might organize by year (2025, 2026), by purpose (Travel, Business), or any other category. Folders are purely organizational — they don't affect financial calculations.

Yes. You can record income and expense transactions with amounts, dates, tags, descriptions, and optional notes. Each transaction can also be marked as paid or unpaid to track bills and obligations. Transactions can be split into breakdown items for more granular tracking.

You can set reminders for transactions or create standalone reminders. When a reminder's date and time arrives, Budgetarian sends a local push notification on your Android device. You can mark reminders as complete or snooze them for later. All reminders are managed locally — no server involvement.

Yes. All your financial data is stored locally on your device using SQLite. Budgetarian does not have a backend, does not collect any data, and does not require an account. Your budgets, transactions, receipts, and settings never leave your phone. See the Privacy Policy for details.

Yes. Budgetarian supports full backup export (JSON format) that includes all your budgets, transactions, tags, and settings. You can also export individual budgets to JSON, Excel, CSV, invoice, or report formats. Backups can be saved to an Android folder of your choice. You can import a backup to restore your data or merge it with existing data.

Since all data is stored locally, uninstalling Budgetarian will delete all your financial data from the device. Make sure to export a backup before uninstalling if you want to keep your records. You can restore from a backup file after reinstalling.

Budgetarian supports multiple display currencies: PHP (default), USD, EUR, GBP, and JPY. You can change the display currency in Settings. All money is stored as integer minor units internally, so no floating-point rounding can affect your balances.

Budgetarian is currently available on Android. iOS support is planned for the future. The app is built with Expo and React Native, which makes cross-platform deployment possible. Stay tuned for updates on the GitHub repository.

Yes. Budgetarian is free and open-source software released under the MIT License. There are no in-app purchases, subscriptions, or ads.

Absolutely! Budgetarian is open-source. You can contribute code, report issues, or suggest features on the GitHub repository. Please read the contributing guidelines in the README before submitting pull requests.
